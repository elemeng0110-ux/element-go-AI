### What Is This?
Element Go Brain Builder is a powerful web app that lets you design your own AI's brain from scratch.

You don't just chat with an AI — you **build the logic that determines how it behaves, thinks, and reasons.**

- Build custom personality & behaviour
- Design logic structure & thinking steps
- Set memory, creativity, and reasoning style
- Use YOUR OWN API key (OpenAI, Gemini, Claude, etc.) - 100% private

Your key stays in YOUR browser. We never store it.

### ✨ Current Features (Live & Working)
- [x] Visual Brain Builder UI
